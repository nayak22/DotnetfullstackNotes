# .NET Full-Stack Notes

Day-by-day study notes for a 74-week .NET full-stack roadmap (0–8 years): C#, .NET, SQL Server, EF Core, ASP.NET Core Web API, frontend, architecture, microservices and system design.

**Live site:** https://dotnetfullstacknotes.appwrite.network/ · or open `site/index.html` locally to browse all weeks. Each week has a home page and seven days with key definitions, quick notes, worked code examples, common mistakes, exercises, self-check questions and interview questions with answers.

## Contents
| Path | What |
|---|---|
| `site/index.html` | All 74 weeks by phase; weeks with notes are clickable and show your progress |
| `site/notes/weekNN.html` | One self-contained page per week (Weeks 1–10 = Phase 1: C# and .NET fundamentals) |
| `prompts/dotnet-notes-prompt.md` | Reusable prompt to generate further weeks in the same style |
| `prompts/kit/` | Page builder (`lib.py`), writing brief, review checklist, and the Python source for each week (`src/`) |

## Phase 1 projects
Toolkit calculator · City Library · Bank simulator · Grade analyzer · Expense tracker · Async downloader · Internals lab · Parking lot system
